# Risk Boundary

Progress: 0% -> 8%

## Forbidden Automatic Actions

- Merge PRs.
- Deploy.
- Promote high-risk skill edits.
- Overwrite `skills/best_skill.md`.
- Convert failed runs directly into active long-term memory.
- Convert arXiv/GitHub/docs findings directly into skill rules.
- Show hidden chain-of-thought.

## Review Required

- Any self-iteration proposal.
- Any high-risk preference candidate.
- Any candidate skill promotion.
- Any external research proposal.
- Any deletion or replacement touching safety or human review sections.

## Runtime Boundary

Default MCP/CLI behavior remains backward compatible. The local runtime path must stay available so CLI/stdio does not hard-depend on an HTTP server.
