# Case Study: StableAgent Recursive Harness

StableAgent Recursive Harness is a personal, evidence-gated self-evolution layer for AI Coding Agents.

It is not a replacement for Codex. It makes Codex and similar coding agents align with the user over time by storing expression preferences, cognitive preferences, task traces, validation evidence, and reviewable skill candidates.

The key product move is controlled recursive self-iteration:

- Every failure can become a candidate skill.
- A candidate skill must pass baseline-vs-candidate A/B validation.
- Human review decides whether it becomes durable.
- Research Watcher turns papers and open-source projects into evidence cards instead of polluting memory directly.
- User Cognitive Profile records how the user explains, decides, and evaluates work.

The result is an agent harness that can get more personal and more reliable without becoming an uncontrolled autonomous self-modifier.
