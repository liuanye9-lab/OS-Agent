StableAgent OS

给 AI Coding Agent 配一套"外接大脑"

StableAgent OS 是一个本地优先的 Agent 控制层，通过记忆路由、上下文预算、追踪观测、评估、技能策展和人工审核，让 AI Coding Agent 更稳定地理解你的意图。

核心类比：学习装备系统

把 StableAgent OS 想象成一套给 AI 学生配备的学习装备，而不是改造学生的大脑。

🎓

大模型 = 学生

Claude / GPT / Qwen / DeepSeek 各有特长，就像不同学生。有的写代码强但容易过度修改，有的推理强但工具调用慢。

👨‍🏫

用户反馈 = 老师

你对模型的每次纠正和反馈，就像老师对学生的指导，帮助模型理解你的真实意图。

📕

Bad Case = 错题本

记录模型犯过的错，形成回归测试用例，避免同一个错误反复出现。

📋

Skill Patch = 学习计划

把失败经验转化为可复用的规则，像学习计划一样指导未来的任务执行。

💼

Agent Capsule = 书包

打包你的记忆、规则、习惯和评测标准，像 U 盘一样在不同 AI 工具间迁移。

📊

Dashboard = 成绩单

可视化展示 Agent 每一步的理解、压缩、判断和学习过程，透明可追溯。

技能生命周期

技能从产生到推广，必须经过严格的验证门控，确保只有真正有效的规则才会进入长期记忆。

关键规则

  • • draft → candidate → validated → promoted → deprecated → archived
  • • candidate 不能直接 promoted，必须先 validated
  • • 只有 promoted 才进入默认检索
  • • 不自动覆盖 best_skill.md
  • • 失败经验不直接写入长期 SkillRepo

推广条件（必须全部满足）

  • schema_valid = true
  • validations >= 2
  • score_delta >= +0.03
  • regression_count = 0
  • event_completeness = 1.0
  • token_delta <= +0.10
  • high_risk_requires_human_review = true
